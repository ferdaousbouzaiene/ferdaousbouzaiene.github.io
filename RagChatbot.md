# 📚 PDF Q&A Chatbot with RAG

## Overview
An experimental chatbot that explores RAG techniques for answering questions from long PDFs. Focused on building the pipeline from scratch.

## Tech Stack
- LangChain, OpenAI API  
- FAISS  
- Streamlit  

## Key Features
- Handles multi-page PDFs with semantic retrieval  
- Explores embedding + chunking strategies  
- Lightweight Streamlit app for demo  

## Impact
- Reinforces knowledge of **vector retrieval** + **RAG best practices**  
- Showcases rapid prototyping of LLM-based apps

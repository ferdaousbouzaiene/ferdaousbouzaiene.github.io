# 📚 Agentellic (PDF RAG QA)

## Overview
An LLM-powered assistant that answers questions from PDF documents. Implements Retrieval-Augmented Generation (RAG) to combine **semantic search** with **GPT reasoning**.

## Tech Stack
- LangChain, OpenAI API  
- FAISS (vector search)  
- Streamlit  

## Key Features
- PDF ingestion, chunking, and embedding  
- FAISS vector store for fast semantic retrieval  
- LLM integration for natural answers with citations  
- Streamlit chat interface  

## Impact
- Demonstrates **modern AI engineering skills**: vector databases, RAG pipelines, LLM integration  
- Practical solution for enterprise document search / knowledge assistants

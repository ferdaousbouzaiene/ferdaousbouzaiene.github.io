# 🎬 Show Recommendation System with LLMs

## Overview
A hybrid movie recommender that blends collaborative filtering, content-based similarity, and GPT-powered semantic reasoning. Generates not only **what to watch next**, but also **why**.

## Tech Stack
- Python, pandas, scikit-learn  
- OpenAI GPT-4  
- Streamlit  

## Key Features
- Collaborative filtering (user-based ratings)  
- Content-based similarity (genres, keywords, metadata)  
- GPT-powered suggestions: “If you liked X, try Y because…”  
- Streamlit UI with natural language input  

## Impact
- Combines **classical ML + LLMs** into a unique recommender pipeline  
- Showcases ability to leverage **large models for explainability**  
- Great demo of applied AI in consumer tech

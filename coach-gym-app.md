# 🏋️ AI-Powered Workout Recommendation System

## Overview
A fitness recommendation engine that generates personalized workout plans based on user preferences, profiles, and goals. Combines classical recommenders, ensemble ML models, and domain knowledge from exercise science.

## Tech Stack
- Python, scikit-learn, XGBoost, TensorFlow  
- pandas, matplotlib  
- Jupyter Notebooks  

## Key Features
- Hybrid Recommendation Model: collaborative + content-based filtering  
- Calorie Prediction Engine: ensemble of Random Forest, XGBoost, and Gradient Boosting  
- Smart Workout Generator: balanced by muscle groups, goals, and constraints  
- Domain Knowledge Integration: BMR calculations, MET values, exercise science principles  
- Interactive notebooks with visualizations & validation  

## Impact
- Delivered personalized workouts with **85%+ accuracy** in preference prediction  
- Calorie predictions within **15% error margin**  
- Proves ability to combine **ML techniques + real-world science** into practical systems
